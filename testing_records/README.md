# 验收记录

这里保存按日期拆分的历史验收记录。总计划只维护当前范围、验收标准、阶段状态和待办；具体执行命令、报告、样本及未验证范围写在对应日期文件。

同一天的多项工作合并在同一个文件中。没有实际验证时不新增日期文件；跨日任务只更新总计划中的当前状态，不复制历史段落。

## 整理约定

- 历史记录结合正文实际日期、版本历史、报告时间和同日上下文归档；后续补验保留实际日期，不用整理日期代替执行日期。证据不足时保留未知范围，不补写没有依据的日期或结果。
- 正式文档保留最终有效内容。已无独立内容的占位、重复快照或迁移说明，移动到 `.cache/`（忽略缓存目录）保存原文件，同时清理正文、索引和技能中的旧路径，不留空文件、转发入口或指向缓存占位的说明。
- 文件索引按日期倒序维护，与日期文件逐项核对，补齐漏项、去重并移除失效项。整理时一并检查其他临时占位与旧引用；日期记录中有用的历史报告位置保留，正式入口和测试不依赖缓存。
