# 素材暂存

`asset_archive.py`（素材暂存工具）用于把已不用的源图片移动到当前工作树的 `.cache/unused-assets`（闲置素材目录），保留语言和模块目录，并记录原路径、暂存路径、字节数与内容校验值。

在当前工作树使用已有虚拟环境解释器，以模块方式运行 `dev_tools.asset_archive`（素材暂存工具）。`move`（预览暂存）后传入一张或多张仓库相对图片路径，也支持通配符。默认只预览，不创建目录或移动文件；添加 `--write`（执行移动）才会暂存。

每批生成一份独立清单。发现目标已存在、源图变化或路径越界时会报错，不覆盖文件；移动中断时保留已移动项的记录。工具不会删除文件，也不会重新生成素材包装。

使用 `verify`（核对暂存）子命令和清单路径，可以重新检查图片内容。上一批骑士团搜索图的清单也兼容，例如：

```powershell
.\.venv\Scripts\python.exe -B -m dev_tools.asset_archive verify '.cache/unused-assets/knights-shop-search-20261007.json'
```

这批17张原图仍位于此前指定的暂存目录；工具不会再次搬动它们。工具测试只创建模拟素材文件，测试产物保留在忽略目录中，可由用户手动清理。
