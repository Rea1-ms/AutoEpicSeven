# 旧活动归档

活动结束后，把实现和调度一起放进对应目录。目录按活动名称和版本日期命名，代码与素材保留，方便以后参考。

| 版本日期 | 活动名称 | 归档目录 | 原有功能 |
| --- | --- | --- | --- |
| 2026-06-25 | 夏日活动 | summer_2026_06_25（2026年6月25日夏日活动） | 每日奖励、任务奖励、免费召唤、能量饮料 |

日期沿用原素材版本标记，不代表国服开放日期。夏日活动国服已于2026年9月17日结束。

每个活动目录同时保留 special_activity.py（活动实现）、scheduling.py（活动调度）和 config.yaml（原配置备份）。源素材继续放在各服务器原有的日期目录，生成的素材定义仍由按钮提取工具管理。

当前日历没有启用夏日活动记录，归档配置也不参与生成。以后恢复旧活动时，先接回对应配置选项和任务绑定，再启用日历记录。
