# 小春活动归档

国际服活动已于2026年10月8日11点结束，2026年10月15日归档。目录日期沿用9月17日的素材版本，也与本期开始日期一致。

koharu_raffle.py（原领奖实现）、config.yaml（原配置备份）和 i18n.json（五种语言的原选项文案）保存在本目录。原入口文件只保留兼容导入，当前活动日历、调度归属和共用侧栏都不再登记该玩法。

源图和生成素材继续保存在原9月17日目录，共用导航及领奖记录仍使用当前公共辅助。共享资料保留本期时间，历史测试直接验证归档实现；归档代码独立保留，不依赖后续梅铃活动。

原流程先把任务列表移到顶部，再领取首行奖励并关闭弹窗。首行“立即前往”表示暂时没有可领的奖励，只有首行完成勾才记录为当天全部完成；不点击任务跳转，也不使用抽奖券。

以后恢复同类活动时，先核对页面和素材，再接回处理表、调度归属和配置选项，使用新的活动标识登记时间。仅修改活动日期不会启用归档逻辑。
