## P2（后续改进）：活动侧栏文字匹配

2026年9月23日记录，暂缓实现，先保留痛点和基本思路。

- 痛点：当晚22:13的日志中，“激战门靡”和“激战门”都能命中关键词，但全文变化会打断稳定判断。20抽名称的尾字变化也有同样问题；INFIN（残缺名称）则无法命中。滚动后疑似回弹被当成边界，最终剩余20抽未领取。日志缺少坐标和对应截图，截断位置与回弹原因仍需核实。
- 思路：保留精确关键词优先，评估 RapidFuzz（模糊匹配库）在固定活动名单内按编辑距离筛选，结合最低分与前两名分差拒绝歧义；阈值用真实截图校准。稳定性比较活动标识和坐标。截半只作查找线索，短滑露全再识别；边界判断区分回弹和真正到底。点击后仍须确认选中态才领奖。
- 后续验证：补充原始文字、候选分数、坐标和滚动状态日志，覆盖错字、尾字变化、截半、相似名称和回弹；识别不确定时保留重试，不记为领取完成。
