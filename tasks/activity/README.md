活动时间现在写在 module/game_info/data.yaml（共享游戏资料）里，任务和甘特图读取同一份数据。字段说明、更新步骤和参考出处见 module/game_info/README.md（资料维护说明）。原 calendar.yaml（活动日历）保存在 legacy/calendar_2026_09_18.yaml（2026年9月18日旧日历快照），不再读取。

国际服有新活动时，增加一条记录并填写起止时间。每日20抽的国服默认顺延21天，维护时间有差异时填写国服覆盖时间。其他类别不会自动套用这个偏移。旧记录保留，到期后自动跳过；相邻活动在交接时间自动切换。同类活动在同一服务器不能重叠，避免把一次领取算作两期奖励。

每期活动使用不同的 id（活动标识），领取记录也按活动和服务器分开。kind（资料类别）描述玩法，活动入口只处理自己支持的类别。新增资料类别可以先用于展示，新玩法的自动操作仍需要补流程和素材。

当前20抽活动的国服截止时间按游戏倒计时核对为11月19日11点。国际服开始日期来自8月27日素材版本，开始时刻暂沿用原国际服截止时刻的2点；这段历史时刻不影响当前调度。

运行 `python -m tasks.activity.calendar`（输出活动甘特图）可以查看最新时间表。calendar.md（活动时间图）是本次生成的快照。

旧活动按日期和名称放在 legacy（旧活动归档）目录。2026-06-25 版本的夏日活动实现和调度保存在 summer_2026_06_25（2026年6月25日夏日活动）子目录，素材沿用原有日期目录。当前活动不再因为竞技场或战斗结束而反复调度夏日奖励。

活动按入口分为两个独立任务。“限时活动”统一走活动入口，包含“领取每日20抽”“领取激战门扉奖励”和“领取小春任务奖励”；“特别活动”处理特殊入口，目前是从主界面进入的德朗商店。两者分别保存启用状态、下次执行时间和失败重试时间，一边失败不影响另一边被调度。德朗商店仍按北京时间11点、23点刷新，只购买神秘奖牌。

升级时，“限时活动”继承原特别活动的总开关、下次执行时间、服务器刷新时间和三个领奖选项；“特别活动”保留原商店购买开关，默认不新增消费授权。迁移只补缺少的新字段，不覆盖拆分后单独修改的设置。领取记录继续使用原有活动标识、服务器及存储位置，因此每日领奖和整期商店固定额度都不会因拆分而重置。后续竞技场、战斗完成只按未完成奖励所属任务唤醒；小春唤醒限时活动，不唤醒商店。

激战门扉、小春和德朗商店目前只支持国际服中文界面。截图和召唤结果识别在“召唤”任务中设置；夏日活动原有的四个奖励选项和任务绑定保存在归档目录的 config.yaml（原配置备份）中。

20抽、激战门扉和小春共用一个活动页状态循环。先处理当前已选中的待办，再按屏幕上的位置处理可见待办；当前屏没有待办时才滑动左侧栏。整轮共用搜索方向和次数，到达底部后最多反向查找一次，不会每做完一个活动就重新上下搜索。全部领取或检查完成后，由总入口统一返回大厅。

点击页签后，要等对应选中态确认才开始领取；文字位置还在移动时不点，点击未生效时重试同一页签。单个活动只负责确认奖励状态和关闭自己的弹窗，完成后停留在活动页面，把控制交回总循环。小春“立即前往”会从本轮待办中移除，但不会记录为当天完成，后续战斗后仍能再来检查。开关关闭、当期已检查的活动直接跳过；整轮都跳过时不操作游戏。活动页中途失败只停止“限时活动”本轮并安排重试；德朗商店由“特别活动”任务执行。旧夏活仍按归档流程处理自己的页面进出。

新增共用活动页的玩法时，在 common_activity.py（活动页状态循环）的 ACTIVITIES（活动处理表）中登记玩法、侧栏文字、选中态素材和领取实现。领取入口保留独立导航，提供 navigate=False（复用已选中的页签）时仍需确认选中态，且成功后必须关闭奖励弹窗并停留在可识别的活动页面。服务器范围、活动时间和配置开关仍由总入口筛选，维护时同时补充可见活动优先、选择确认和单项失败的离线验证。

新增活动还需在 calendar.py（活动日历适配）的 ACTIVITY_TASK_MODES（任务玩法归属表）中选择归属。共用入口的玩法归 LimitedActivity（限时活动），特殊入口归 SpecialActivity（特别活动）；各任务只读取自己玩法的开放时间和刷新节点。限时活动的日完成判断使用自己的服务器刷新设置，旧记录虽然保留原存储位置，也不会读取特别活动的重试时间。

左侧导航在 COMMON_ACTIVITY_LIST（活动列表区域）内识别包含 INFINITY（活动名称）的文字，点击文字位置后，再用 FREE_20_GACHA_SELECTED（20抽页签选中态）确认切换成功。列表有滚动时，先确认文字位置不再移动，再点击；未找到时在列表内有限滑动查找，不需要未选中页签图。

2026年9月19日补充了国际服20抽页签的独立选中态素材。原通用模板在国际服已选中的侧栏截图上仍识别失败，会导致反复点击；国服继续使用原模板。维护时要用实际侧栏截图验证完整选择流程，确认已选中时不会再点击，并检查未选中、滚动后位置和其他活动。不能只检查文字识别正确，或只拿模板自身做匹配。截图与切图配方保存在主检出目录 test/screenshots/activity_navigation（活动导航测试资料）中。

小春活动沿用同一个侧栏导航，查找“收集抽奖券”，再确认选中态和页面标题。进入后先把任务列表移回顶部，领取首行奖励并关闭弹窗；已领取任务会排到后面，继续检查新的首行。

小春的“立即前往”只表示暂时没有可领的奖励，不会记录为当天全部完成。后续竞技场或战斗完成时，会按原有奖励调度规则再次检查。只有首行出现完成勾，才按活动和服务器保存当天完成记录，直到服务器刷新后重新检查。领取过程不点击任务跳转，也不使用抽奖券。

## P2（后续改进）：活动侧栏文字匹配

2026年9月23日记录，暂缓实现，先保留痛点和基本思路。

- 痛点：当晚22:13的日志中，“激战门靡”和“激战门”都能命中关键词，但全文变化会打断稳定判断。20抽名称的尾字变化也有同样问题；INFIN（残缺名称）则无法命中。滚动后疑似回弹被当成边界，最终剩余20抽未领取。日志缺少坐标和对应截图，截断位置与回弹原因仍需核实。
