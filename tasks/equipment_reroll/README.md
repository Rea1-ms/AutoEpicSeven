# 装备副属性刷新

先在游戏里选好装备，停留在钢铁工坊的副属性选择页，再从工具启动。

四种属性分别填写目标值，按重要性排序。速度固定先追 5，达标前不锁任何属性；其他属性达标后才锁定，最多两条。百分比只填数字，小属性单独选择。

启动时先检查设置。速度目标填 4、属性重复或预算不合法时，日志会显示具体原因；目标填写错误还会标明第几项和当前数值，不自动修改用户设置。日志说明使用英文，原始中文识别内容照常保留；需要人工检查时，先记录严重错误原因，再停止。

初始锁定按用户填写的目标顺序检查，只允许锁住从第一顺位开始、连续达标的前两项，可以少锁。其他属性、未达标属性或排在未达标目标之后的属性被锁定时，直接停止，不替换、不自动解锁，也不刷新。例如第一顺位是生命值 8%，但当前生命值只有 6%、速度 5 已锁定，就会报错。这里新增的是初始检查，后续刷新仍保留速度优先规则。

次数和点数预算填 0 表示不限。达标、预算用完或点数不足时停止，保留当前最好结果，不自动制作装备。支持截图所示的简体中文界面；识别或扣费无法确认时停止并提示检查。

点击替换后会核对弹窗中的属性，再点“应用”。确认居中的当前属性已更新后，才继续锁定或刷新。

主属性在进入工具前已经选定，这里不再读取。锁图标只需一份模板，按四行位置分别匹配；行距 47 像素，每个匹配框向四周留 2 像素，相似度要求 0.85，开锁和闭锁必须只命中一种。

灰色文字分数偏低时，再用另一种对比度处理确认内容；内容一致且置信度达到 0.8 才使用，否则继续等待稳定画面。

属性名称使用中文模型，数字和百分号使用项目已有的英文模型，避免短数值在中文模型下持续低分。两种模型都需要可用，不自动下载或安装。

确认过的名称在本次运行中保存为图片模板，后续先匹配图片；陌生或不明确的名称仍需文字识别，不能当作没有目标属性。名称匹配相似度要求 0.98，完整文字尺寸必须相近，并与其他名称拉开至少 0.03 的差距。临时模板不会跨运行保存。

速度和暴击伤害另有真实截图切出的名称素材，启动时直接载入；速度包含亮字和灰字两份，避免启动时灰色名称持续低分。素材只包含名称，速度数值仍独立识别，不把 4 当成 5。上面不跨运行保存的是临时学习的模板。效果命中副属性暂缺真实样本，遇到时仍需文字识别。

每轮先检查右侧四条属性前的金色标记。没有金色且文字连续两帧稳定，就继续刷新，不识别未锁定的候选名称和数值。有金色时只识别这些行的名称，命中当前阶段目标才读取对应数值；阶段按用户优先级推进，有速度要求时先追速度 5。

金色用于筛选，不能代替数值确认：已有真实截图里速度 4 也显示金色，仍需识别到 5 才锁定。攻击、生命、防御必须识别百分号，区分小属性。目标数值有改善时，汇总四条属性再决定是否替换，已确认的锁定行使用记录；弹窗和替换后的当前属性仍完整核验。

启动时读取锁定属性的名称和数值，检查目标顺序以及左右两列是否一致，确认后保存。后续灰色锁定行直接沿用记录，不再匹配名称、数值、金色标记或文字轮廓；左侧锁图标仍检查，用于确认锁定操作和价格。替换开始时清除当前装备记录，实际应用后重新读取并确认。

未锁定行的名称和数值仍按文字轮廓参与连续两帧稳定检查，深色背景动画不会重新触发等待；标记颜色不明确或文字尚未完整显示时继续等待。未锁定行已读取的数值仅在对应小块图片完全相同时复用识别结果。

持有点数在启动时读取，之后按确认完成的刷新估算，每 10 次及正常退出前重新识别核对；核对不一致或识别低分时，记录英文严重错误并停止。价格使用真实截图切出的 20、60、150 模板，必须与零、一、两条锁定一致，不再进行价格文字识别；锁数与价格尚未同步时继续等待。

每次付费点击后，仍须看到余额数字轮廓变化、未锁定候选结果连续两帧稳定，才计入次数和消耗；锁定属性沿用已确认记录，图片比对忽略亮度及深色背景变化。不确定时不重复点击刷新。两次点数核对之间的扣费是估算值，不逐次识别实际扣除金额。

当前装备在启动确认后记录，刷新和调整锁定时直接使用记录；替换开始时清除旧记录，确认当前属性实际更新后再记录一次。画面亮度和左右列位置变化不会触发当前装备的重复识别。
