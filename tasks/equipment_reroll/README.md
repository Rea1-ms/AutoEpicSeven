# 装备副属性刷新

先在游戏里选好装备，停留在钢铁工坊的副属性选择页，再从工具启动。

四种属性分别填写目标值，按重要性排序。速度固定先追 5，达标前不锁任何属性；其他属性达标后才锁定，最多两条。百分比只填数字，小属性单独选择。

次数和点数预算填 0 表示不限。达标、预算用完或点数不足时停止，保留当前最好结果，不自动制作装备。支持截图所示的简体中文界面；识别或扣费无法确认时停止并提示检查。

点击替换后会核对弹窗中的属性，再点“应用”。确认居中的当前属性已更新后，才继续锁定或刷新。

主属性用于检查目标是否与它重复，弹窗里不重复读取。锁图标只需一份模板，按四行位置分别匹配；行距 47 像素，每个匹配框向四周留 2 像素，相似度要求 0.85，开锁和闭锁必须只命中一种。

灰色文字分数偏低时，再用另一种对比度处理确认内容；内容一致且置信度达到 0.8 才使用，否则继续等待稳定画面。

属性名称使用中文模型，数字和百分号使用项目已有的英文模型，避免短数值在中文模型下持续低分。两种模型都需要可用，不自动下载或安装。
