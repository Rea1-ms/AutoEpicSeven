## 从新局自动布阵

自动布阵从首轮、场上0人的稳定准备页开始，完整扫描候补后建立本局名单。按姓名选人会先重新核对整条候补，再回到目标；目标以下的卡片也必须确认，不能找到名字就忽略剩余名单。每次召唤或赠送后，调用方需要传入明确收集的英雄结果，再结合完整候补刷新。场上角色升级也需要有前后刻印相接的结果，重复结果不累计升级；未知获得、漏失英雄或无法解释的变化会停止。

开局扫描结束后立即布阵时，可一次性复用刚核实的名单。要求仍为同一个截图对象、像素未改、名单未换、没有新增英雄结果，而且距扫描完成不足3秒；换图或超时仍重新扫描。如果首个布阵目标正好是扫描末尾已选中的人物，重新核对其姓名、刻印和队尾标记后直接打开选格，不再次遍历候补。这项复用只用于开局第一步，之后仍核对每次动作的完整结果。同一截图里的文字和数字读取结果也会在当前识别步骤中共用；换图后核对当前字形及状态，相关字段未变时复用已确认读数。

阵容仍按已有评分选择，逻辑前排对应屏幕最右一列，逻辑左右列对应屏幕由上到下的行。已有正确站位保持不动，先换入需要的人物，再移动到目标格；位置互相占用时借用已核对占格以外的空格。选人、开选格、移动和取消按各自已确认的状态推进；仅同一按钮重试保留间隔。切换候补后需要下一张新截图确认队列一致，末卡和目标卡也不能直接使用移动中的首帧。目标和减号只点一次，返回准备页后重新完整扫描候补，再打开选格核对全部占格；姓名、刻印、人数、格位及资源均符合预期才更新记录。已有身体模板不是这条流程的必需条件。

自动布阵按已校准的棋盘坐标点击目标格，不再要求目标黄边完整。选格模式和棋盘定位通过后，蓝色换人图标与选中人物的绿色标记共同核对全部占格，数量须与实际上场人数一致；空位由这些占格以外的棋盘坐标确定。黄边只保留为辅助观察，人物或图标遮住黄边不会阻止移动。满场时从候补打开仍只能换人，选中场上人物后可以移动；来源格不能成为自身目标，缺少占格标记或移动结果不符仍会停止。

5/5这类满员换人会隐藏所有空格边框，原先用于定位的特定占格边框也可能恰好不在当前阵容中。两处边框锚点均缺失时，改由数量与满员人数一致的蓝色换人图标共同校准坐标；各图标须对应唯一格位，并符合相同的小幅位置偏移。缺图标、位置冲突或人数不符仍停止，完整候补和换人后占格核对保持。

关闭核对网格统一点击顶部 Round（回合）文字，使用用户确认的无额外功能区域；重复点击当前主选人物会打开人物介绍，不能用来取消选格。取消前仍核对网格、人数和候补，之后还要看到稳定准备页。名单只用于已完整核对的会话；手动插入操作或未确认的动作会使会话失效，占格集合相同不能证明两名人物没有被手动对调。重新启动普通存局时重新恢复身份，失败会保留最后确认的名单供检查，该名单不能继续授权点击。

调用接口为 `BrawlFormation`（自动布阵），先调用 `begin`（从新局初始化），需要安排时调用 `arrange`（刷新并执行推荐布阵）；职业天赋必须明确传入，没有加成时传空字典。`refresh`（核对名单）接收已收集的英雄结果，`invalidate`（使会话失效）用于未跟踪的外部操作。调用方应准备首帧，并沿用已有设备；这些接口不会自行连接模拟器、抽卡、传送或开战。

格位、候补选择和开局使用正式截图核对；整队动作顺序、取消选格和失败分支使用明确模拟的画面状态与时钟，保留生产动作间隔。用户已实测开局两名英雄布阵完成；新增跨回合串联尚待实机验证，不能将模拟通过视为整局已经可运行。

## 使用

界面入口为左侧「工具 → 大乱斗」，使用已有的开始、停止和运行日志。支持国际服简体中文、1280×720。可直接从主页启动，经「战斗 → 赛季 → 大乱斗」到大厅；有存局点击继续，没有存局则保持大厅当前模式，在确认免费后入场。未采集付费入场报价，因此不会猜测费用或点击未确认免费的入场按钮。每次启动先到大厅的「遗物 → 和谐遗物」读取六职业基础羁绊加成，再继续存局或进入新局。已经在稳定准备页时，通过右上角「暂停 → 保存并退出」返回大厅；读取后只点击「继续战斗」，核对原回合、等级、上场人数、容量和两种余额一致，再恢复人物身份。若从暂停菜单启动，先点「返回」取得未遮挡的准备页面板。

首回合空场按当前金币优先升级，升不起下一级后再普通召唤，直到完整候补名单的人数达到当前上场上限或金币不足。每次召唤核对结果、实际扣款与完整名单，重复英雄只更新刻印。余额不足以补满时使用已有英雄；一名英雄也没有则不能开战。随后使用本次启动已确认的职业天赋；普通模式逐轮经营、布阵和作战，挑战模式打一场并核对奖励、再次布阵后停止。启动时应关闭其他弹窗或选格。

普通存局先完整扫描候补、核对全部占格，再逐格识名。有候补时临时换入一人，从两次完整名单的唯一差异读出被换出者的姓名和刻印，然后换回；满10候补也使用这条路径。无候补时逐格下场识名，再放回原格。每次换出和还原都核对完整候补、人数和资源；占格在下一次实际操作前核对，最后再统一验阵，省去中途另开网格再取消的重复点击。原阵容确认还原后才接续经营。后续回合空场也可恢复候补与天赋。停止按钮会终止当前运行；重新启动会重新核对，不沿用旧记录。

加号显示的是全部站位，不能独自确认每人的姓名和刻印，存局的逐人识名仍保留。有空位且有候补时，后续只读站位核对也从当前候补的加号打开，不再为此先点场上人物。完整扫描刚结束、目标就是当前选中人物时，同一截图可直接复用一次结果，避免立即重扫；截图、像素、操作或短时有效期变化后重新读取，滑动遍历和人物切换仍保留原有确认。每次身份往返恢复完整候补后，以及布阵步骤通过完整候补和占格核对后，才重置重复点击记录；未确认操作和只读开关选格不会重置保护。

选中格任一侧都可能被人物遮住。存局占格核对与下场识别使用绿色放大镜和红色减号的唯一配对，分别确认本帧颜色及相对格位；不再依赖某两条必须露出的绿边。完整占格、指定源格与目标格、人数仍须一致，缺失或错位按钮不会授权操作。操作前和返回准备页时核对必要面板，页面、模式及当前数字字形未变时复用读数；空候补使用明确的空栏标记，不重复识别提示文字。中断后若仍显示选格，先点顶部 Round（回合）文字退出，再启动工具。

六职业天赋统一从「和谐遗物」的职业图标及节点顶部边框读取：青蓝为已激活，已知灰色或白灰为未激活。页面、选中页签和全部六图标必须完整，连续两帧读数一致后才返回。这里不识别文字，也不点击节点；未知颜色、缺失或错位图标不记为零。每次启动重新读取，不沿用账号旧设置，也不扣除场上职业人数。当前真实和谐截图为六项均激活；未激活颜色分支使用其他遗物树真实灰框进行明确的合成测试，仍需未激活账号的和谐实图补充验收。

不再为读取天赋整队下场。人物身份仍按上一段逐人换出或下场识名并立即还原，最后核对完整名单、刻印、原站位与资源，再交给经营。保存返回期间若存局消失，或者继续后的准备面板改变，保留当前画面停止，不改点新局。攻击、生命等属性天赋无需额外采集。暂停、保存、页签、返回、继续各自只请求一次，新截图确认下一状态后立即推进。工具任务不加入日常调度。运行日志说明使用英文，游戏原始姓名和识别结果保留原文。

从仓库根目录使用已有项目解释器运行 `python -B -m tasks.brawl.brawl --image "截图.png" --out ".cache/brawl-report.json"`（分析截图并保存新报告）。图像必须是1280×720；输出文件已存在时拒绝覆盖。该命令只读截图，不读取账号配置或连接模拟器。

当前使用本工作树已有的项目解释器，业务代码与正式样本均从当前工作树读取，没有安装或升级依赖。

可选参数 `--roster`（完整阵容资料路径）读取结构化文本。必须明确填写 `complete`（完整标记，值为真）、`round_number`（截图回合）、`level`（截图等级）、`heroes`（场上和等待队列的完整英雄列表）及 `class_bonuses`（职业天赋加成）。每名英雄填写 `name`（英雄名）和 `imprint`（刻印）；白板写 `NONE`（无刻印），不能省略。职业天赋用职业中文名和0或1填写，没有加成时明确给空字典。

名单来自人工提供，不能当作已经完成图像识别。回合与等级不符、缺少刻印、重复英雄，或名单超出当前上场人数至上场人数加10的范围时拒绝推荐；同回合手动召唤、布阵或传送后，也需要重新填写。战后可能赠送英雄，因此旧回合名单不沿用。

## 阵容建议

阵容按完整队伍评分，计算实际达到的羁绊档位，同时考虑稀有度、刻印、已解锁的大招和近远程搭配。职业天赋单独传入，不默认全部加一。评分权重是初版经验选择，没有用实战胜率校准；小名单枚举组合，大名单保留有限候选，不宣称战斗最优解。

站位建议给4×7交错棋盘的逻辑格，行0表示靠近敌人的一排。近战优先前排，远程优先后排；黎洁特射程3、露彬射程1、莱娅射程2单独处理，卡萝与卡麦萝兹虽为魔导士，射程均为1，按近战放置。莱娅优先第二排是当前策略选择，不代表游戏强制站位。自动布阵负责转成屏幕行列，再用当前选格画面确定点击位置。尚未根据实际敌方阵容、女仆聚光灯或攻击力最高目标调整。

传送收益按本局实际取得份数和局外是否拥有计算，不能只看当前刻印。已满刻印后的新重复英雄按白板自动传送。攻略里连续两条同名刻印的例子保留为原始记录，不推断第二条是哪一档。

参考自走棋项目只用于理解按人数选阵容、整队羁绊评分和前后排安排，代码独立实现。没有沿用其他游戏的利息、商店刷新、三合一或点击后直接扣余额的做法。

## 连续作战与每轮经营

左侧工具中的大乱斗先从和谐遗物读取天赋，再进入新局或存局。新局按升级优先规则准备候补并布阵；普通存局完整恢复后进入相同经营流程。挑战存局保留原阵容打一场。每场只点击一次战斗开始；战斗期间支持两倍速，单轮胜负画面等待自动跳转。战斗结束后的英雄弹窗先读取姓名、前后刻印，再点击底部继续；相同结果重复出现不重复入账，连续刻印升级保留顺序。货币收益直接读取返回准备页的实际数值，不推算固定奖励。

普通模式重新进入准备页后，先确认完整资源面板和候补状态连续稳定超过0.6秒，再沿用本次建立或恢复的名单与天赋，完整扫描候补、核对原有占格，先把战后奖励记录用于解释新增人物和刻印变化，再开始下一轮经营与布阵。金币结算或候补淡入期间只读取画面，不滑动候补；读数变化会重新确认稳定，但不会延长原有的局部等待上限。败退返回同一回合也按这次实际奖励和余额重新决策，不沿用旧面板；确认完成后再次开战。挑战模式仍保持原来的单场处理。升级、召唤、传送、开战、奖励关闭与布阵按确认状态推进，同按钮重试保留独立间隔，战斗本身没有短超时。

本次开战后出现「网络连接异常，请重新连接」时，优先复用公共网络模板和轻触箭头，不读取弹窗后的暗色资源。当前帧确认弹窗及重试箭头后即可请求，重复请求至少间隔5秒，同一次异常最多等待30秒。重试保留这次开战和奖励记录，恢复准备画面也不会再点开始；只有看到真实战斗才结束这次断网计时。明确断线到登录流程、箭头始终缺失或重试超时则保留画面停止，重新启动后恢复存局。

每轮金币够升级就先升级，缺人数才普通召唤，缘分币够40且候补有空位时抽上级。当前队伍、下一级推荐阵容及后续较高羁绊档位所需的人物列为保留目标。传送报价通过逐名选入、读取并取消取得；每次取消都核对名单没有改变。确定可支付升级且留下足够补位人物后，再选择最多5人的完整批次，核对总报价并只确认一次。报价仅用于同一版名单；赠送英雄、刻印或资源变化后重新计算。满级满候补时每回合最多腾一个位置，赠送英雄重新填满也不在本回合重复出售。策略是经验评分，不保证最优阵容。

无法辨认的英雄结果、无法解释的名单变化、未知增益选择、总等级提升或英雄解锁均保留画面并停止；明确的整局胜负也留在结果页。召唤出现满刻印重复英雄时，读取结果页的自动传送标记，关闭后按准备页实际金币和缘分币增加确认返还；零返还或负差额停止。离线状态回放中的重复帧、计时与跨回合面板为明确模拟，现有截图之间存在未记录的换人，不能当作无人干预的完整实机录像。
