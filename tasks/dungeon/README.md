# 智能均衡刷符文

精灵祭坛新增“智能均衡刷符文”，默认关闭，目前使用国际服中文素材。开启后，按每名五星角色需要普通45、上级22、传说16的比例比较五色库存，优先补养成份数最少的颜色。比较保留小数，不会因为五色都凑不齐一套就始终选同一种。

难度按实测每场产出和体力消耗比较，估算补齐下一套养成缺口所需的组合。组合中有多个难度时，先刷对当前最缺档位更有效的那一个。当前样本下，普通主要刷初级，上级和传说主要刷地狱；中级、上级祭坛仍参与比较，后续更新样本或体力消耗时可能重新选中。不会自动合成，也不把富余的低档符文直接算作高档库存。

估算保留原始总数，不把四位小数当作精确爆率。按这组均值，从零补齐一套需要约11.24场初级和73.78场地狱，模型体力约986.5；实际掉落有波动，也必须整场、整批执行。这些小数只用于比较难度，不会作为完成判据或自动修改已有批次数。

沿用原有批次数、行动力和生命之叶设置。开始新一批前读取库存，已有后台战斗先等待结算，再读取实际库存并重新选择。每日模式仍按日运行，燃竭模式继续按行动力调度。当前开关不会改动账号配置或主动开始采样战斗。

识别使用“成长材料”的截图排列，按图标定位数量，不按固定格子认符文。零库存的条目会消失：只有符文前后的相邻材料都可见、两者之间没有未识别的格子，才把缺少的类型记为零。数字识别失败、列表未完整显示、排序与截图不一致时会停止并提示检查；已有十五种都完整识别时不要求相邻材料存在。连续两帧结果一致才使用。

十五种符文和前后两种相邻材料共用 `RUNE_INVENTORY_LIST`（符文列表区域），每次识别时设置搜索范围，数量区域的边界检查也使用它。后续调整范围只需修改这一块源图并重新生成素材定义，无需为每个图标单独维护搜索范围图。

后续采样记录刷前、刷后普通／上级／传说数量，以及实际完成场数、宠物和掉落活动状态。期间不合成、消耗或额外领取符文。日常结算后继续重读真实库存，不用模型预测代替识别；目前不会把可能混有其他来源的库存增量自动追加到这组样本。

# 托管战斗进度

国服和国际服中文共用进度识别区域。准备页已有预计时长时，继续按原来的时间检查；接管手动开启的托管，或预计时间已过但还没结束时，再打开详情读取进度。

- `OCR_SETTLEMENT_PROGRESS`（战斗进度区域）读取已完成场数和总场数。
- `OCR_SETTLEMENT_TIME_SPENT`（已用时间区域）读取时、分、秒，不是剩余时间。
- 剩余时长估算为“已用时间 ÷ 已完成场数 × 未完成场数”，再沿用一分钟检查余量。估算只决定下次检查时间，不表示战斗已经结束。

详情页标题在运行中和结算时相同。出现“中断”才按运行中详情处理：读取后用 `AD_BUFF_X_CLOSE`（广告增益关闭按钮）关闭，并确认回到可识别的页面；不会点击“中断”。真正完成仍走结算、关闭奖励和返回页面的流程。

进度为零、已完成全部场数或已用时间为零时，无法继续推算，保留会话并按一分钟间隔检查。识别失败会短暂重试，之后保留已有有效预计时间；没有有效时间就按一分钟间隔检查。进度读数不会清除会话，也不会改动紧急任务的后续安排。

后续界面变化时，先更新上述两块源图并重新生成素材定义。解析和估算在 `repeat_progress.py`（进度识别实现），打开详情、关闭和调度在 `repeat.py`（托管流程实现）。验证应同时覆盖两服素材、识别失败、零进度、满进度、点击未生效，以及读取途中转入结算；测试仍放主检出目录被忽略的测试文件夹。
