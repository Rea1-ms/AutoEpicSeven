# 每日主线材料

在每日副本选择“主线材料”，再设置目标材料和第一至第五篇章。旧配置默认使用第四篇章。第一篇章只使用攻略表中提供的稀有催化剂关卡；第二、第三和第五篇章支持表中的催化剂；第四篇章保留催化剂及原有四种养成材料。材料下拉按当前篇章筛选：绿荫心脏、业火气息、酷寒种子和光辉痕迹仅在第四篇章显示，并统一放在末尾。切换篇章后，原材料不适用时显示重新选择提示，保留已保存的材料，不自动替换；切回适用篇章可恢复原选择。

从地图右下角的蓝色按钮进入篇章选择页，按标题确认目标篇章后，点击任意可进入章节卡片上的星星，再通过文字识别和左右箭头切到目标章节。8S（章节编号）和10S（章节编号）保留字母，避免误当作普通第八章或第十章。

篇章和章节文字读取成功后复用结果，查找材料时不重复读取；切换篇章或章节后再读取新编号，识别失败才重试。关卡编号仍在选关操作后读取，用于判断目标是否在当前位置上方。

进入目标章节后沿用原来的四个选关分支：右侧掉落预览出现目标材料就进入战斗；当前关卡在目标之后就把列表向上滚动；左侧找到目标材料图标就点击；否则点击列表下方继续查找。支援、备战、快速战斗及重复战斗仍使用共用流程。

托管战斗按钮不可用时，改从备战页顶部读取资源，有可用次数的快速战斗仍可执行。快速战斗未开启、锁定或次数耗尽，同时托管也不可用时，会提示检查宠物和普通战斗通关记录；不会把没有执行的刷取记作完成。快速战斗结果页显示次数耗尽，与托管按钮不可用是两个独立状态。

配置已生成，相关离线识别和回放已通过；重启工具后可使用新增篇章选项。本次跨篇章材料刷取尚未实机验证。

# 剧情推进

先手动打开要推进的主线章节页或支线剧情列表，再在工具页选择“剧情推进”，按当前页面选择主线或支线。使用当前队伍，自动跳过剧情、开启自动战斗并处理结算。与每日材料刷取独立，只在手动启动时运行；从主页启动会提示先进入目标页面。

主支线共用剧情进场加速：已有“跳过”就直接点击，不等集数、标题或对话文字出现。尚无跳过时，识别右上历史图标，在空白处尝试一次；图标持续存在、重复帧和短暂黑屏都不会再次触发。确认回到地图、支线列表、备战、助战、战斗或结算后，下一段才可重新尝试。点击空白不延迟随后出现的跳过及确认；未生效时等待游戏原有动画，不连续点击。

“跳过”按钮出现后按0.5秒间隔重试，处理开场第一次点击未生效的情况。确认按钮仍按原两秒间隔重试，第一次确认及其他新状态可立即处理。

主线检查通关与锁定标记，选择已解锁、未完成的节点，沿用下一章箭头继续。章节识别、列表滚动、支援及备战入口与每日材料刷取共用。队伍准备页保留颜色检查以排除弹窗遮挡。工具从用户打开的当前篇章开始，不再提供冒险部数选择，旧设置保留但隐藏。

支线使用独立循环，不读取主线三星条件。返回列表后按游戏已选中的下一项点击“观看”或“准备战斗”，不处理活动入口、活动选择和其他布局。通过当前章节及选中行标题确认节点变化，避免旧画面重复播放；“观看”会消耗行动力，发出一次请求后等待进入剧情，不按普通导航按钮反复点击。

章节和选中标题读取成功后，同一列表复用结果；每帧仍检查可操作页面、选中标记及文字字形。章节或标题变化、进入剧情或战斗后返回列表时重新读取；背景变化、点击未生效和短暂未知画面不单独触发重读，读取失败仍允许重试。

支线当前选中节点图标出现绿色完成勾时，按已结束正常停止，不再点击“观看”或读取费用。只认当前选中行的完成勾，前面已完成节点的绿勾不会让工具提前停止。末段在本次运行中已确认进入才计数；直接从结束页启动不补记旧节点，也不重播最后一段。

第六关辅助英雄页曾因“选择队伍”按钮旧素材相似度约0.847、未达到0.85门槛而停留。现为国际服中文的共用按钮补充第二帧，保留旧素材和原门槛；问题截图及点击未生效时的两秒重试已通过离线验证，实机尚未复测。更新后需完全停止并重新启动工具，加载新素材定义。

“最多推进节点”默认为0，表示持续推进；战斗和纯故事各算一个节点。主线确认结算后返回无遮挡地图才计数；支线确认返回列表且选中项已变化，或已有结算证据后计数。重复画面不会重复计数，达到上限会先结清当前节点。

体力不足、关卡未解锁、章节入口持续不可用或识别超时会停止，日志记录原因；战败和背包满需要人工处理。准备页同时出现“故事队伍”标记、右上角满星条件最后一行含“攻略”时，才报错停止，提示手动满足满星条件后再启动工具。普通队伍即使含“攻略”也继续；故事队伍最后一行不含“攻略”也继续，包括只允许一名角色入场的关卡。判断先于体力读取、开战和通关计数，不依赖人数或文字颜色；仅故事队伍需要读取最后一行，空白会短暂重试，持续十二秒仍无法读取则停止，离开该准备状态就清除等待计时。不会补充体力、自动确认购买、补位或更换英雄。队伍需事先准备好。

地图右下入口显示“探险”时，直接报错停止，提示手动完成后再启动工具；不会点击进入，也不会将旧结果提前计入通关数。仅识别该入口文字并检查正常颜色，普通战斗入口及被弹窗遮暗的页面不会据此停止。

体力费用和可用体力连续三次读取相同后，在当前准备页复用，不再逐帧识别。确认前若读数变化或识别失败，会重新累计；离开准备页就清除读数和等待计时，下次进入重新读取。体力不足仍立即停止，开战重试仍按原两秒间隔执行。

战斗中先确认自动按钮和暂停键的图案，再比较两者亮度；暂停键正常亮起、自动按钮明显变暗时，表示该战斗无法开启自动战斗，立即停止并提示手动完成后再启动工具。这个判断使用灰度和相对亮度，减少半透明按钮随背景变色造成的漏判；整体被弹窗遮暗或任一图案缺失时，不据此报禁用。主支线共用剧情跳过和自动恢复：剧情关闭自动后，识别手动按钮及亮起的战斗控件，再重新开启；精英敌人没有编号也能处理。技能动画里暂时不显示准星和技能自动标识，不会仅凭这些标识缺失就点击。

主线入口支持国服和国际服中文，实图验证以第六部简体中文1280×720画面为主；用户此前实机通过一个纯故事节点，并确认准备页开战及战斗后的剧情跳过已执行。第一至第五部、跨章节和连续多关尚未实机验证，旧版地图布局可能不同。支线目前仅支持国际服中文，44张顺序截图覆盖第一、第二章的剧情、备战、战斗和返回列表；本轮验证为模拟设备回放，尚未实机复测。

新增主线素材保存在 `assets/share/dungeon/episode`（主线素材目录），按地图、战斗、剧情和奖励分组；通关展示沿用 `assets/share/dungeon/state`（共用战斗状态素材目录）。正式脱敏截图和可重放切图配方随测试保存；配方引用相对路径，未包含个人截图目录。

# 智能均衡刷符文

精灵祭坛新增“智能均衡刷符文”，默认关闭，目前使用国际服中文素材。开启后，按每名五星角色需要普通45、上级22、传说16的比例比较五色库存，优先补养成份数最少的颜色。比较保留小数，不会因为五色都凑不齐一套就始终选同一种。

难度按实测每场产出和体力消耗比较，估算补齐下一套养成缺口所需的组合。组合中有多个难度时，先刷对当前最缺档位更有效的那一个。当前样本下，普通主要刷初级，上级和传说主要刷地狱；中级、上级祭坛仍参与比较，后续更新样本或体力消耗时可能重新选中。不会自动合成，也不把富余的低档符文直接算作高档库存。

沿用原有批次数、行动力和生命之叶设置。开始新一批前读取库存，已有后台战斗先等待结算，再读取实际库存并重新选择。每日模式仍按日运行，燃竭模式继续按行动力调度。当前开关不会改动账号配置或主动开始采样战斗。

识别使用“成长材料”的截图排列，按图标定位数量，不按固定格子认符文。零库存的条目会消失：只有符文前后的相邻材料都可见、两者之间没有未识别的格子，才把缺少的类型记为零。数字识别失败、列表未完整显示、排序与截图不一致时会停止并提示检查；已有十五种都完整识别时不要求相邻材料存在。连续两帧结果一致才使用。

十五种符文和前后两种相邻材料共用 `RUNE_INVENTORY_LIST`（符文列表区域），每次识别时设置搜索范围，数量区域的边界检查也使用它。后续调整范围只需修改这一块源图并重新生成素材定义，无需为每个图标单独维护搜索范围图。

后续采样记录刷前、刷后普通／上级／传说数量，以及实际完成场数、宠物和掉落活动状态。期间不合成、消耗或额外领取符文。日常结算后继续重读真实库存，不用模型预测代替识别；目前不会把可能混有其他来源的库存增量自动追加到这组样本。

# 讨伐目标

讨伐按怪物立绘选择目标，再检查同一张卡片的亮色边框。阿吉玛纳克和食人魔都使用暗属性图标，因此属性图标不再作为讨伐的识别依据；精灵祭坛仍按属性选择。

默认选择双足飞龙，可以直接选择六种怪物名称。食人魔固定使用异界难度，使用上方的独立入口，隐藏不适用的难度、快速战斗和刷空体力设置。

立绘素材不包含文字，各语言共用。列表位置变化后重新匹配，按目标所在方向滚动；没有找到目标时停止，不使用上次的匹配位置点击。

六种立绘共用 `HUNT_CARD_SEARCH`（卡片搜索区），使用源图保留区域，不再额外向外扩展；点击区域就是立绘本身。选中边框使用 `HUNT_CARD_SELECTED`（卡片选中边框）的独立窄搜索区，按当前匹配到的立绘高度检查，不受点击区域调整影响。

异界托管每场可消耗1个光谱核心或2片生命之叶，生命之叶数量按钮每次增减2片。配置仍表示生命之叶数量：最低按2片执行，较大的奇数向下取偶数；设置4片时，从2片只增加一次。只有新截图确认实际数量达到目标才继续，不把异界的生命之叶按每片80点预留行动力。

# 托管战斗进度

国服和国际服中文共用进度识别区域。准备页已有预计时长时，继续按原来的时间检查；接管手动开启的托管，或预计时间已过但还没结束时，再打开详情读取进度。

- `OCR_SETTLEMENT_PROGRESS`（战斗进度区域）读取已完成场数和总场数。
- `OCR_SETTLEMENT_TIME_SPENT`（已用时间区域）读取时、分、秒，不是剩余时间。
- 剩余时长估算为“已用时间 ÷ 已完成场数 × 未完成场数”，再沿用一分钟检查余量。估算只决定下次检查时间，不表示战斗已经结束。

详情页标题在运行中和结算时相同。出现“中断”才按运行中详情处理：读取后用 `AD_BUFF_X_CLOSE`（广告增益关闭按钮）关闭，并确认回到可识别的页面；不会点击“中断”。真正完成仍走结算、关闭奖励和返回页面的流程。

进度为零、已完成全部场数或已用时间为零时，无法继续推算，保留会话并按一分钟间隔检查。识别失败会短暂重试，之后保留已有有效预计时间；没有有效时间就按一分钟间隔检查。进度读数不会清除会话，也不会改动紧急任务的后续安排。

后续界面变化时，先更新上述两块源图并重新生成素材定义。解析和估算在 `repeat_progress.py`（进度识别实现），打开详情、关闭和调度在 `repeat.py`（托管流程实现）。验证应同时覆盖两服素材、识别失败、零进度、满进度、点击未生效，以及读取途中转入结算；测试仍放主检出目录被忽略的测试文件夹。
