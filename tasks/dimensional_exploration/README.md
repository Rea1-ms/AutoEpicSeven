次元探查目前支持国际服中文界面的“星之旅程·归途”。在任务列表中设置探查轮数和各职业英雄优先名单后启用；完成指定轮数会关闭本任务开关，再次启用会开始新一批。中途停止后保留已完成轮数，已有探查会继续进行。

每轮打到通关或失败，以出现有效最终分数的整局结算为准。普通战斗胜利、重复结算截图和仅招募后放弃都不会多算轮数。难度沿用游戏当前设置；新一轮默认选择“沉重包袱”。队伍沿用游戏配置，战斗中根据手动操作标记开启自动战斗。

当前持有的次元核不足20时，商店优先于事件；达到20后，事件优先于商店。其后依次选择补给、精英战斗、普通战斗、休息；首领为必经节点时正常进入。只选择带可前进标记的节点，已走过和未开放的节点不会参与排序。

商店始终先投资，包括次元核已达到20的情况。再按需恢复生命体征、购买额度内的战利品，不提取次元核，也不购买招募券。事件优先选择带图鉴标记的已知奖励，检查生命、战利品和碎片代价；次元核不足20时为下次投资保留50碎片。优先保留最后一点生命；遇到没有离开选项、只能消耗最后生命的事件时，按游戏规则结束并结算本轮。休息优先恢复生命体征、复活、治疗，最后升阶；补给优先战利品。战利品三选一优先速度、攻击、暴击和伤害相关效果，不使用骰子重抽。

英雄名单按从左到右排序，可用大于号、逗号或换行分隔。先搜索名单中的可负担英雄；有限搜索后仍没有名单内候选，则选择可负担的低额度英雄。初始招募为剩余位置各预留2点额度。确认招募前再次检查左侧选中英雄和当前额度，滚动期间不使用旧坐标。

当前验证以用户提供的103张截图为基础。已覆盖页面识别、可达节点、商店资源与确认、事件选项、招募滚动、失败结算和轮数恢复；成功通关后的额外弹窗、入口列表滚动及实际队伍变化仍需实机验证。无法识别的商品、事件代价或英雄选择会保存截图并停止，不能作为本轮完成。

维护素材时使用 dev_tools/exploration_assets.py（截图裁剪配方）生成根目录源图，再定向运行按钮生成器。包装文件由生成器维护。离线测试位于主检出目录的 test/test_dimensional_exploration.py（次元探查回归测试），从当前工作树运行。
