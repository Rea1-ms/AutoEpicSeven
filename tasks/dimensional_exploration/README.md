次元探查目前支持国际服中文界面的“星之旅程·归途”。在工具栏中设置探查轮数、开局策略和各职业英雄优先名单后，点击开始独立运行，不参与主调度器。完成指定轮数后自动停止，再次点击开始会运行新一批。末次结算后返回主页时被中断，也按已经达标处理，不需要再点第二次启动。未达目标时中途停止，仍保留已完成轮数并继续已有探查。修改轮数后，旧计数已经达到新目标时从新批次开始。

每轮打到通关或失败，以整局结算和可读取的星辰气息获得量为准。普通战斗胜利、重复结算截图和仅招募后放弃都不会多算轮数。难度沿用游戏当前设置；开局可选“雇佣契约”“痛苦机械装置”“沉重包袱”“基础锻炼铁锤”，默认“雇佣契约”；确认前检查所选卡片的金色边框。已有配置保留用户选择，新增配置及缺少该项时使用新默认值。队伍沿用游戏配置，战斗中根据手动操作标记开启自动战斗。

当前持有的次元核不足20时，商店优先于事件；达到20后，事件优先于商店。其后依次选择补给、精英战斗、普通战斗、休息；首领为必经节点时正常进入。只选择带可前进标记的节点，已走过和未开放的节点不会参与排序。

次元核大于20时，商店优先购买买得起的 N（未收录）战利品，再投资、按需恢复生命体征、购买其他战利品；正好20核及以下仍先投资。没有买得起的未收录战利品时照常投资，不因达到20核而停止。未收录战利品有多个时先买价格低的，不提取次元核，也不购买招募券。未收录标记通过橙色徽标模板识别，按位置对应到商品，日志会列出识别结果。首次购买前连续两帧确认完整商品信息，之后沿用这份记录，避免购买浮窗遮住名称和标记。每次仍核对确认框的名称、价格与货币；连续两帧读到付款后的碎片余额，才开始下一次购买。短暂误判为地图不会清空付款记录；实际选择下一个可达节点后，才清空上一间商店的记录。

休整时，全队平均血量严格低于30%就按“复活、治疗、恢复生命体征、升阶”选择可用选项。其他情况仍先恢复生命体征，再复活；任一英雄低于30%，或全队平均低于60%时才治疗，否则升阶。平均恰好30%不切换顺序，平均恰好60%且无人低于30%不触发治疗；未达到治疗条件且不能升阶时直接离开。恢复生命体征与复活或治疗同时可用时，会先从“英雄”读取连续两帧一致的完整血量；其他需要判断治疗的情况也先查看名单，不读取不完整名单或推算屏幕外英雄。只有升阶，或查看血量不会改变选择时，不额外打开名单。补给优先战利品。战利品三选一优先速度、攻击、暴击和伤害相关效果，不使用骰子重抽。已有选中卡片时直接确认，重启后的独立领奖页也继续领取。点击历史只在连续两帧确认进入新房间、战斗结束或付款成功后清理；同一页面反复点击仍会触发卡死检测。

事件按“事件表、选择策略、操作与记录”分别管理，借鉴无声综合征的逐事件配置和模拟宇宙的选项优先级。事件表保留截图来源、叙述关键词、完整选项、代价、奖励和重复选择优先级；这些事件没有独立标题，表中的名称只是方便维护的描述。新的选项或数值变动不能直接按旧规则点击，需要先补充事件表。

events/event_catalog.json（事件决策表）目前整理了43个独立事件，按后续选择拆分为52个阶段，全部已有策略。同一事件只要有一项优先级留空，就不会自动选择，自动采样也不会绕过。具体决定和采样证据见 events/event_review.md（事件整理与待决定项）。事件表支持生命体征上下界、是否满生命体征、最低碎片余额、后续阶段预留碎片，以及明确禁止选择的分支；回血条件支持全队平均血量或任一英雄低于指定值。修改后重启任务即可使用，不需要生成账号配置。

放大镜只用于查看奖励详情，不代表尚未收录。第一次遇到有专属战利品的分支，会在可负担且保留最后一点生命体征的前提下尝试；之后沿用事件表的重复路线，通常优先低消耗；古剑、面具等按用户明确指定的路线选择。同一物品有多个获取分支时，不会为了“首次”重复付款或战斗。随机奖励未出现也只记录尝试，不会冒充已获得；不会重复开启已尝试过的观测站投币路线。

骰子、碎片、战利品、随机英雄生命值、全队生命值、生命体征分别记录。准备选择英雄回血或扣血分支时，先点左上角“英雄”，用原生进度条识别读取完整名单的血量，连续两帧一致后返回事件。扣血按最低血量检查，每名可能被扣血的英雄在扣除后都须至少保留25%，恰好25%允许；读不齐或看不清时继续等待，不推算缺失英雄。同一已识别事件的文字识别差异不会清空血量，实际结果或进入其他阶段后才重新读取。生命值是短血条的近似比例，和顶部生命体征分别处理。

积水牢房在全队平均血量严格低于70%，或任一英雄严格低于25%时，优先免费恢复全队10%；否则免费拿50碎片。选择碎片前也要先确认完整血量，不能因为碎片免费就跳过检查。平均使用完整名单的总血量与人数比较，真实零血量计入，不先四舍五入；回血不会复活死亡英雄。

断墙老妇人在生命体征大于2时优先消耗1点，其次支付100碎片，最后随机英雄扣40%生命值。支付碎片仍保留投资预算；随机扣血须所有可能目标至少65%，扣后各留25%。商店已有购买确认价44及商品页45碎片，均低于100，但不作为所有商店的固定价格。消耗生命体征已由五张实图确认：4/4降到3/4，本次随机获得次元水晶柱，战利品3变4，碎片407不变，并有两页后续叙述和返回地图。次元水晶柱不是固定或专属奖励；100碎片分支按用户约定下次遇到再采集，可开启事件自动采样照常记录。

微弱火光首轮只选择休息或尝试战利品，不选扣血换骰子。全员至少55%时优先第3项，以全队30%生命值尝试获得战利品；有人低于55%则选第1项恢复15%。首轮未获得战利品时，后续选择“现在就撤离”，不再承受40%扣血；已经获得时，也选择“只带上目前获得的东西并撤离”，不继续追加30%扣血。两种后续分别登记，重启遇到它们也直接撤离。

残破石碑全员至少50%时优先“拓印无名纹样”，扣全队25%生命值后每人仍留至少25%，获得随机战利品。有人低于50%则“查看石碑下方的缝隙”，免费拿50碎片并离开；这页没有直接离开项。仍先读取两帧完整一致的血量，不按顶部生命体征推算。随机获得的具名物品只作为本次观察，不记作事件专属奖励；重复遇到也按当前血量选择。

两条岔路先检查完整英雄血量。全员至少75%时优先左路，随机一人扣50%后仍保留25%，获得随机战利品；否则走右路，献祭一件普通战利品恢复全队生命值。只按普通灰色边框选择，不固定物品名称，粉色边框的特殊战利品保留；只剩特殊物品或无法确认类型时停止。重启遇到已选中的物品会先取消选择，再确认普通类型，不能直接消费。右路回血不会复活死亡英雄。献祭选择页也会采样，选中1/1仍不算完成，出现后续叙述才确认结果。

网络异常出现时先等待倒计时，识别到“点击重试”后再按原有动作间隔点击，恢复后继续当前页面。异常遮罩不确认事件结果，不会因此重复选择或重复增加采样次数。

巨眼事件先显示开场叙述，需要点击后才出现三项选择；这一页没有继续箭头。现在用完整开场文字模板确认画面，再点击叙述区，仍按原有两秒动作间隔重试。已有选项时不会使用开场点击；文字不完整或其他未知叙述也不据此推进。开场点击不记录已选分支或已获得奖励，三项完整出现后才按原策略选择战斗。素材和点击范围见 events/introduction_assets.json（开场素材配方）。

次元核不足20时，事件花费碎片后须为投资保留50碎片。因此观测站首次投币至少需要220碎片，不足20核时需要270；再次启动需为70、100两个阶段保留170，最后阶段需要100，投资额度另算。当前阶段资源不足或被游戏禁用时选择离开。生命体征不足以保留最后1点、资源未识别或遇到未知代价时，会保存截图并等待人工处理。

事件记录保存在当前配置中，独立于批次轮数；完成任务、重开和重启均保留。点击本身只记录待确认分支，出现后续叙述、奖励、战斗或地图才记录已走过；只有由选项操作进入的对应奖励卡片才记录已获得。已有账号的完整游戏图鉴不会自动导入，不同账号应使用各自配置。

积累新事件时可以开启“事件自动采样”，默认关闭。开启后不必逐个手动截图：已有和未登记事件都会保存选择前、后续叙述、奖励、升阶领奖、已核对的下一阶段选项、战斗入口和返回地图等画面，以及原始选项文字、选择理由、前后资源读数和差值。多页叙述分别保存，重复画面不会多记次数。文件保存在项目截图目录下的 dimensional_exploration_events（事件采样）文件夹，按配置和事件归档，索引会列出各分支已经完成的采样次数。每次最多保存12张后续画面，不会逐帧保存战斗录像；文件保留供后续批量整理，不自动删除。

采样模式下，已有事件继续按事件表选择。未登记事件须连续两次读到相同文字和资源，才按通用规则尝试：未显示代价的选项优先，其次是可负担的局内货币；有离开选项时避免牺牲战利品、英雄生命值或进入战斗。同样低消耗的分支优先选择采样次数少的；已尝试过的付费选项会让位给离开。不会单纯为了补齐分支而增加代价。未显示代价不保证后续没有负面结果，采样会把真实结果保留下来。

看不清或无法解释的消耗、资源不足、会耗尽生命体征的选择仍会停止并保存现场。采样次数只有出现明确后续画面才增加，重复帧和中断重启不会重复计数。采样结果只是原始资料，不会自动写入永久事件规则或冒充图鉴解锁；积累后再集中核对事件表。

英雄名单按从左到右排序，可用大于号、逗号或换行分隔。开局先搜索名单中的可负担英雄；有限搜索后仍没有名单内候选，才选择可负担的低额度英雄，并为剩余位置各预留2点额度。局内招募仍优先名单英雄；已知所有未招募目标都超过剩余额度时，直接选当前页可招募的其他英雄，不因优先名单买不起而放弃招募券。新读到的费用也会立即用于判断；当前页无人可选时，回查之前读到的可负担英雄。全职业招募合并六个职业的优先名单，按画面从左到右、从上到下，先遇到可负担的名单英雄就选；当前页没有则逐列滚动。到末尾或达到原有搜索上限仍未找到，选择当前页可负担的其他英雄；末页没有候选则回查之前读到的可负担英雄。确认招募前仍检查选中英雄和实时额度。

职业名单会排除本局已确认招募的英雄和已知超出本次额度的目标，再按原顺序顺位。逐行识别到当前第一优先级且可招募的英雄，就停止后面的姓名和费用识别；两次读到一致的候选位置后才点击。全职业招募遇到任意职业名单内的可招募英雄就停止后续识别，不要求继续寻找名单排序更靠前的英雄，也会跳过本局已招募者。目标费用未知时仍先搜索，到末尾或原有上限没有可招募目标，再选择已读到的可负担英雄。局内职业招募的名单已补齐时直接返回；开局仍允许补齐队伍。

横向滚动后按姓名和费用是否完整显示判断可读范围。左侧卡片边缘被遮住，但这两个字段仍完整时照常读取；右侧费用被截断时继续滚动，不按可见的半个数字或缓存猜价格。

本局招募记录保存在当前账号的任务会话中，重启保留，正常进入新一局时清空。确认按钮点击后先保存待确认角色；连续两帧读到与该角色费用一致的招募额度增加，才记为已招募并顺位。点击失败、旧画面、未知页面或额度上限变化都不会冒充成功。此记录只包含脚本确认过的招募，中途启用时不会猜测此前手动招募的角色；也不按角色阵亡自动移除记录。

费用表由连续一致的英雄列表自动积累，灰色不可招募英雄的费用也能学习，不需要手工维护。费用文件保存在 data/dimensional_exploration（运行数据目录），国际服中文共用一份，不再出现在左侧账号配置列表。启动时自动合并旧费用记录，并将旧文件完整移到该目录的 legacy（旧记录）子目录。未知费用仍读取游戏列表，缓存不能代替招募前的实时额度检查。退出一次可选招募后，本次领奖不会马上再次打开它。

正常一轮大致是：活动标题 → 章节与大厅 → 开局补给与招募 → 地图 → 房间预览 → 房间。事件、商店、休整、补给完成后回到地图；战斗则经过准备、战斗、领奖，再回地图。最终胜利或失败后进入整局结算，读取星辰气息获得量并增加一次轮数，回大厅继续下一轮或结束。中途重启时直接识别当前页面，不要求重新从标题开始。

不同操作各自保留必要记录。商店保留选中商品和付款前余额，连续两帧确认扣款后才买下一件；招募保留从稳定列表确认的姓名与费用，选中后核对详情和剩余额度，额度变化就重新选择；领奖页保留本次是否主动跳过招募，出现未领取提醒时才决定确认或返回检查。完全没有可负担英雄时仍可退出招募；已经确认只奖励英雄的当前事件，明确跳过后可以确认离开，叙述文字不会造成“继续、取消”往返。未知奖励或缺少事件依据仍返回检查，重启遇到未领取弹窗也先取消。

战斗采用现有副本流程的自动战斗标记。已进入战斗时，技能动画暂时遮住按钮仍视为战斗；只有明确的手动操作标记才会触发开启自动。开局就是无法识别的画面时，不凭空认定正在战斗。出现领奖、地图等明确页面后，战斗记录结束。

同一页面的文字与详细内容最多每秒识别一次，页面变化后立即处理，点击仍受两秒间隔限制。这样能减少卡点期间的重复计算；实际处理器占用还要在模拟器上确认。无法执行操作的已知页面持续约40秒会保存现场并停止，战斗动画不受这个短超时限制。仍在反复点击却没有明确进展时，由框架原有的卡死和连续点击保护处理。异常截图使用项目截图目录，停止原因也先写入日志。

升阶优先级逐行填写“英雄名=目标阶数”，例如“起源拉斯=3”，阶数为1至5。启动前检查每个名称是否在六个职业的英雄优先名单中，名称不一致、重复或阶数格式错误会直接报错。填写顺序就是目标达成顺序；某个目标英雄确实不在当前队伍时跳过，目标全部完成后按英雄优先名单补到5阶，最后升其他英雄。留空直接按英雄优先名单升满；都到5阶时返回并离开休整。
