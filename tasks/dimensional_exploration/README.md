次元探查目前支持国际服中文界面的“星之旅程·归途”。在任务列表中设置探查轮数和各职业英雄优先名单后启用；完成指定轮数会关闭本任务开关，再次启用会开始新一批。中途停止后保留已完成轮数，已有探查会继续进行。

每轮打到通关或失败，以出现有效最终分数的整局结算为准。普通战斗胜利、重复结算截图和仅招募后放弃都不会多算轮数。难度沿用游戏当前设置；新一轮默认选择“沉重包袱”。队伍沿用游戏配置，战斗中根据手动操作标记开启自动战斗。

当前持有的次元核不足20时，商店优先于事件；达到20后，事件优先于商店。其后依次选择补给、精英战斗、普通战斗、休息；首领为必经节点时正常进入。只选择带可前进标记的节点，已走过和未开放的节点不会参与排序。

商店始终先投资，包括次元核已达到20的情况。再按需恢复生命体征、购买额度内的战利品；战利品优先 NEW（未收录）标记，再按价格选择，不提取次元核，也不购买招募券。首次购买前连续两帧确认完整商品信息，之后沿用这份记录，避免购买浮窗遮住名称和标记。每次仍核对确认框的名称、价格与货币；连续两帧读到付款后的碎片余额，才开始下一次购买。离开商店后清空商品记录。

休整优先恢复生命体征、复活、治疗，最后升阶；补给优先战利品。战利品三选一优先速度、攻击、暴击和伤害相关效果，不使用骰子重抽。已有选中卡片时直接确认，重启后的独立领奖页也继续领取。点击历史只在连续两帧确认进入新房间、战斗结束或付款成功后清理；同一页面反复点击仍会触发卡死检测。

事件按“事件表、选择策略、操作与记录”分别管理，借鉴无声综合征的逐事件配置和模拟宇宙的选项优先级。事件表保留截图来源、叙述关键词、完整选项、代价、奖励和重复选择优先级；这些事件没有独立标题，表中的名称只是方便维护的描述。新的选项或数值变动不能直接按旧规则点击，需要先补充事件表。

放大镜只用于查看奖励详情，不代表尚未收录。第一次遇到有专属战利品的分支，会在可负担且保留最后一点生命体征的前提下尝试；之后采用低消耗路线。同一物品有多个获取分支时，不会为了“首次”重复付款或战斗。随机奖励未出现也只记录尝试，不会冒充已获得；目前不会为概率奖励反复支付高额代价。

骰子、碎片、战利品、随机英雄生命值、全队生命值、生命体征分别记录。英雄生命值百分比不会当作生命体征扣除；当前尚未读取每名英雄的剩余生命值。次元核不足20时，事件花费碎片后须为投资保留50碎片。生命体征不足以保留最后1点、资源未识别或遇到未知代价时，会保存截图并等待人工处理。

事件记录保存在当前配置中，独立于批次轮数；完成任务、重开和重启均保留。点击本身只记录待确认分支，出现后续叙述、奖励、战斗或地图才记录已走过；只有由选项操作进入的对应奖励卡片才记录已获得。已有账号的完整游戏图鉴不会自动导入，不同账号应使用各自配置。

积累新事件时可以开启“事件自动采样”，默认关闭。开启后不必逐个手动截图：脚本会保存选择前、后续叙述、奖励、战斗入口和返回地图等画面，以及原始选项文字、选择理由、前后资源读数和差值。文件保存在项目截图目录下的 dimensional_exploration_events（事件采样）文件夹，按配置和事件归档，索引会列出各分支已经完成的采样次数。每次最多保存12张后续画面，不会逐帧保存战斗录像；文件保留供后续批量整理，不自动删除。

采样模式下，已有事件继续按事件表选择。未登记事件须连续两次读到相同文字和资源，才按通用规则尝试：未显示代价的选项优先，其次是可负担的局内货币；有离开选项时避免牺牲战利品、英雄生命值或进入战斗。同样低消耗的分支优先选择采样次数少的；已尝试过的付费选项会让位给离开。不会单纯为了补齐分支而增加代价。未显示代价不保证后续没有负面结果，采样会把真实结果保留下来。

看不清或无法解释的消耗、资源不足、会耗尽生命体征的选择仍会停止并保存现场。采样次数只有出现明确后续画面才增加，重复帧和中断重启不会重复计数。采样结果只是原始资料，不会自动写入永久事件规则或冒充图鉴解锁；积累后再集中核对事件表。

英雄名单按从左到右排序，可用大于号、逗号或换行分隔。开局先搜索名单中的可负担英雄；有限搜索后仍没有名单内候选，才选择可负担的低额度英雄，并为剩余位置各预留2点额度。局内职业招募只补名单内的英雄；已知所有目标都超过剩余额度时直接退出，不再滚动尝试。全职业招募券按当前画面从左到右、从上到下选择首个可负担英雄，不搜索优先名单。确认招募前仍检查选中英雄和实时额度。

费用表由连续一致的英雄列表自动积累，灰色不可招募英雄的费用也能学习，不需要手工维护。费用文件保存在配置目录，按当前配置隔离；未知费用仍读取游戏列表，缓存不能代替招募前的实时额度检查。退出一次可选招募后，本次领奖不会马上再次打开它。

当前验证使用用户提供的截图，包括新增的长剑事件。已覆盖页面识别、可达节点、商店资源与确认、事件选项、招募滚动、失败结算和轮数恢复；成功通关后的额外弹窗、入口列表滚动及实际队伍变化仍需实机验证。无法识别的商品、事件代价或英雄选择会保存截图并停止，不能作为本轮完成。

维护素材时使用切图工具调整根目录源图，再定向运行按钮生成器。文字识别、颜色检测和点击范围均从资产读取；重复商品、战利品和休整选项使用多帧资产，浮动英雄和事件选项的区域随已识别图标平移。生成器直接从源图的非黑像素边界生成识别和点击范围，同时计算默认搜索范围与颜色。仅在默认值不合适时补充属性图；目前只有事件战利品数量需要 AREA（识别区域）覆盖，避免空计数源图把范围缩成一个小标记。业务代码不另存坐标。dev_tools/exploration_assets.py（截图裁剪配方）用于初始化缺失源图，默认保留已有图片，覆盖时须显式指定参数。包装文件由生成器维护，不能手改。离线测试位于主检出目录的 test（测试）文件夹，从当前工作树运行。
