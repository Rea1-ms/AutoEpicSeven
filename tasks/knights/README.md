骑士团商店随每日骑士团任务检查，周常和月常商品分别设置本期目标购买次数，默认全部为0。确认买够后，逐件把本期已买数量保存到当前账号配置，重启后仍保留；下次直接跳过这些商品，全部完成就不再进入商店。手动已买的数量也计入目标，首次仍需进入商店连续两帧核对同一商品的库存；读数变化、识别失败、画面移动或弹窗打断时重新确认，避免单帧误读导致整期跳过。余额不足时只买当前可负担的数量，下次任务继续检查未买够的商品。

周常记录在服务器周一刷新时过期，月常记录在服务器每月1日刷新时过期，使用现有服务器时区及每日刷新时间。刷新后重新核对游戏库存，不把旧记录当作新一期已完成；跨过刷新时间的运行仍记在进入时的周期。同一期调高目标数量会补买差额，关闭某项不会清除已有记录。只有目标已由库存证明达到，或付款后连续核对库存减少，才保存已买数量；未确认的付款不写完成记录。

支援、商店、每周任务使用同一个骑士团任务对象，按这个顺序执行已开启的项目。进入各页签都走全局导航，页签之间直接切换，全部完成后才关闭活动面板。正常显示的活动面板不会再被当作广告关闭；有弹窗遮盖时仍保留原有恢复处理。

商品卡片用图像定位，实际点击同一张卡片下方的价格按钮。弹窗沿用普通商店的处理方式，通过按钮图像区分单件、多件和二次确认；商品身份使用本次识别并点击的卡片记录，不再识别弹窗中文名称。多件数量沿用普通商店的数字计数读取，确认当前数量和按钮后，按差额批量加减，每批最多3次、间隔0.2～0.3秒。批后等待短暂稳定再读，部分生效时只补剩余差额；最小、最大快捷按钮仍单次点击，结果同样重新核对。连续确认目标数量后才购买；二次确认核对独立的弹窗及购买按钮图像。两层确认分别只点击一次，付款后连续确认剩余次数减少，才处理下一件。

同名炼制石箱按限购次数和货币区分；85级、88级魔石箱用等级数字图像区分。库存、余额、卡片价格和可调购买数量仍需数字识别；库存区域保留完整宽度、缩紧上下边缘，避免卡片背景把5/10误读成字母，不把字母猜成数字。数量栏中的“¥1/5”“1/5双精灵”沿用现有商店计数读取处理。不可识别或数量与卡片库存不符时等待下一帧，不猜测数量。断线返回后保留两层确认的点击状态，重新定位商品。

横向滑动在德朗商店原有幅度上再缩小20%，每次272像素，等待画面稳定再检查两排商品。正常新进入页签就在左边界，不做入场复位或向右找起点的动作。页签亮起后还要匹配实际商品图像，先检查当前商品；查找的首次滑动也遵守2秒动作间隔，不再切页后立即拖动。商品未显示时继续截图等待，无法确认时按原有上限报错。只有画面稳定、目标不在当前视野时才向左小幅拖动查找右侧商品。商品买完可能移到末尾，因此任何商品都不作为固定的终点。已经检查过的目标保留记录；购买后重新定位原商品核对库存，仍先向左拖动查找后续商品。只有本次提交过购买、到达末尾仍缺少目标时，才向右拖动查找可能移到前面的商品。断线重新进入商店同样先核对商品画面，保留付款记录。目标未核对完成时会报错，不把到达边界当作购买成功。

顶部三种货币会随余额位数一起改变位置，现在先匹配各自的图标，再读取图标之间的余额。四位数的“1,010”不会再被固定区域截成“010”；缺失或重复的货币图标也不会沿用旧余额。

目前支持国际服简体中文截图中完整可见的18项周常、月常商品。账号限购、无限购买以及截图未完整显示的商品不在本次范围。已用实机截图和用户日志做离线回归；神秘奖牌和魔罗戈拉同屏、售罄月常炼制石箱移到末尾均已有实图验证。2026年10月4日用户反馈测试通过。单件弹窗布局、自动排序后的连续购买在离线回归中仍使用明确模拟帧验证。
