# 月塔

月塔位于工具分类，只能手动启动，不加入定时调度。已接入国际服简体中文和国服流程。正常逐层战斗，处理遗留装置选择，检查自动战斗和二倍速，并从列表或备战页读取实际楼层。

## 最终结算

国际服简体中文的末层结算显示“征服”，不是“下一层”。脚本点击“征服”，关闭专用提示，再看到月塔入口的“征服”状态才算完成；超时则保留现场。国服末层结算仍待补图。

## 行动力

开爬前读取剩余行动力，每层开战前重新读取该层消耗。日志按当前层的费用粗估可爬层数，后续每层以实际费用为准。

国际服简体中文可在月塔详情启用“行动力不足时用叶子补充”，默认关闭。勾选后显示保留数量，取消勾选不会清空已填数量。修改后按账号自动保存，下次启动生效。只在确认选中叶子档且保留量足够时换取 80 点行动力；确认余额增加后才重新开战。行动力不足且无法用叶子补充时，尝试关闭已弹出的补充窗口，直接结束本次任务，不返回主界面、不使用钻石。

## 调试采集

在月塔详情勾选“记录装置调试截图”即可自动保存，下次启动月塔时生效。默认关闭，按账号保存，与装置方案分开。

边刷边收集资料时，选择“原第一张策略”并点击“使用所选方案”，再启用调试采集。原策略无需识别装置名称，未登记的装置也能留下图片；已有选择仍按原流程确认。启用装置方案时继续遵守方案规则，调试开关不会将识别失败改成随意选择。

每轮保存三选一出现时和首次确认前的两张完整画面，附楼层、服务器、选择方式、已识别候选及确认状态。原策略不额外识字，未识别的名称和位置保持未知，可根据图片事后整理。重复点击只增加确认请求次数，不重复保存图片；进入预期后续页面才记录为已确认。保存失败会告警并关闭本次采集，原有选择和重试继续执行。

图片和记录位于 screenshots/automaton_tower_debug（调试截图目录），依次按账号、服务器、本次运行和轮次区分，启动日志显示本次目录。每次启动新建目录，旧记录保留；全部是本地调试材料，不自动纳入版本控制或装置资料库，收集完可整理整个运行目录。测试及采集缓存不自动删除。

## 国服与入场弹窗

已保存本次提供的 27 张国服截图和 1 张国际服赛季弹窗，正式副本转为 RGB（图像颜色模式）并遮盖账号信息，原图保留。国服素材覆盖活动入口、阶段选择、首次确认、楼层列表、备战、战斗控件、三选一及第一层结算。两服复用同一套战斗流程和手动工具入口。

两服都有阶段选择和首次入场确认。本次国服确认只开始当前所选阶段，不自动切换难度或重置；国际服这两处仍缺截图，专用处理待补。两服赛季信息弹窗都先关闭，再操作背后页面，关闭未生效时限频重试。

国服三选一只提供了中间选中的正例。左右选择使用等距布局及同一高亮颜色判断，没有制作虚假的左右素材；左右选中实图仍待补齐。装置背包的两张截图作为资料和反例保存，暂不据此恢复完整持有列表。第一层结算不能证明最终全塔通关。

本次新增 9 项回归及相应样本登记，按用户要求暂不运行测试。国服适配、两服弹窗及受影响的页面导航均待执行验证，之前国际服的通过记录不能代表本次改动已通过。

## 装置方案

在月塔任务详情中选择方案并点击“使用所选方案”，下次启动任务时生效。未启用方案时保持原第一张策略。

内置“后排盗贼输出示例”用于说明格式，请先“复制并编辑”，填写自己的队伍和顺序。保存会新增用户方案，保留旧文件；导入同名方案也不会覆盖。导出只包含方案文本，不带账号及获得记录。

方案使用 YAML（配置文本）。装置名称从同目录的 device_catalog.json（装置资料库）复制，填写完整名称，不能缩写或只填关键词。目前收录截图可核实的 16 种装置。未登记名称会保存截图并停止，待资料补齐后重试。资料库中的等级只代表对应截图，不推算其他级别的名称或收益。

```yaml
版本: 1
方案名: 我的月塔方案
队伍:
  主输出职业: 盗贼
  主输出位置: 后排
装置优先顺序:
  - 装置: （盗贼）基本技能连射装置
    条件:
      主输出职业: 盗贼
  - 后排英雄强化装置
  - 暴击率强化装置
禁选装置: []
名单外处理: 第一张适用装置
识别失败处理: 暂停
```

顺序从高到低。规则中的“装置”也可以填写名称列表，表示同一优先级，同级按从左到右选择。支持的条件是“主输出职业”“主输出属性”“主输出位置”和“队伍包含英雄”，同一规则多个条件需全部满足。没有命中时，可以选择第一张适用装置或“暂停”；明确禁选不会参与回退。

队伍中还可以填写“英雄”列表，每名英雄包括“姓名”，以及可选的“职业”“属性”“位置”；“主输出”填写列表中的一个姓名。最多四名，姓名和站位不能重复。职业支持骑士、战士、盗贼、射手、魔导士、精灵师，属性支持火焰、寒气、自然、光明、黑暗，位置支持前排、后排、上方、下方。主输出画像用于说明已知信息，不等于其他三人也属于该职业或属性；只有完整四人资料才能证明某类英雄不在队伍中。缺少会影响选择的信息时暂停说明。

任务会读取全部三张卡，核对完整名称与等级，改选方案目标后检查蓝色高亮，再点击决定装置。确认按钮绿色只能证明已有选择，不能代替目标确认。停止时保留当前画面，并将异常截图保存在月塔装置截图分类中。

用户方案保存在 config/automaton_tower（本地配置目录），运行记录保存在 data/automaton_tower（本地运行目录），两者均不纳入版本控制。每次启动独立记录三张候选、实际楼层、选择原因及确认状态；点击不代表获得，只有预期后续画面才记为已确认。记录始终是部分观察，不能作为完整背包或跨期持有证明。

完整设计和待补截图见 DESIGN.md（设计说明）。背包恢复、持有组合规则和自动英雄识别尚未接入。
