主界面的账号等级只在确认主页无遮挡后读取。普通等级保留为 Rank（普通等级）1—70，超阶保留为 S.Rank（超阶等级）1—20；不能只取数字，否则超阶 1 级会被当成新号。普通 70 级和所有超阶等级都按已解锁光辉里程碑处理。前缀不明确、数字越界或识别失败时，结果为未知。

等级识别范围放在 OCR_ACCOUNT_LEVEL（账号等级识别范围）素材中，国服和国际服共用。这是文字识别范围，不是拿“普通 69 级”去匹配其他等级的图像模板。当前两个样本已经验证普通 69 级和超阶 20 级都能完整读取。后续等级上限变动时，调整 account_level.py（账号等级解析实现）中的校验，并补对应样本。

活动和秘密商店入口随光辉里程碑解锁向下移动。这两条主页路由已经启用 match_before_click（点击前匹配）：使用当前截图定位成功后才点击，随后仍由目标页面识别确认跳转成功。未找到入口时继续获取截图；同一路由连续无法定位达到 8 秒且至少检查 5 次，就报页面识别异常，不按默认坐标点击，也不把任务记为完成。固定入口继续沿用原有点击方式。

等级只影响候选顺序：未解锁先试上方，已解锁先试下方，识别不到等级就按素材顺序全部尝试。不同服务器的素材编号顺序不同，因此按素材的纵坐标排序，不写死“第二张就是高等级布局”。优先候选不匹配时，仍会尝试另一套；每次点击使用这次匹配得到的独立坐标，不能复用按钮封装中上次选中的素材。

目前在导航确实需要这两类入口时读取等级，结果只保留在当前任务实例，下一次匹配前重新读取，不依赖其他任务先采集、不写入长期配置。非主页或有遮罩时不读；识别失败会清除本次等级提示，不能沿用另一个账号的结果。日志保留识别原文，并输出最终匹配素材与点击区域。

以后增加可变入口时，在 Page.link（页面连边）上显式声明点击前匹配，并准备覆盖真实位置的搜索区域或多套素材，不根据素材数量自动决定策略。当前主页的上下排序适用于光辉里程碑引起的下移；若其他入口有不同移动规则，需要单独指定排序，不能照搬等级规则。

回归测试在主检出目录的 test/test_main_navigation.py（主页导航测试）。验证包含普通和超阶解析、国服和国际服的两种布局、等级提示错误、当前截图没有入口、旧匹配后切换布局、确认页面时出现遮罩，以及已有固定路由与两秒点击间隔。测试包含实际截图识别和素材摆放的导航重放，不能替代实机验证。
