国服和国际服简体中文先读取三姐妹日记，再根据未完成项目安排已有任务。目标是达到100活跃并领取全部奖励。关闭“每日任务优先”时只领取奖励；国际服其他语言暂时保持原领奖流程。

两服共用一份每日观察、领奖确认和进度保存实现，素材按服务器语言选择，不再保留分服实现文件或兼容入口。

执行顺序统一在原调度优先级表中维护：重启、每日领奖、召唤、圣域日常、竞技场、战斗，再执行其他自动任务。企鹅购买和装备重铸属于手动工具，不列入调度表，仍从工具菜单启动。每日进度不再额外重排任务；关闭每日优先或达到100活跃后也使用这张表。仍只执行已启用且已到期的任务，保留原等待时间。每日优先开关继续控制分批补缺口和进度回查。

两服当前均支持13项每日任务，包括三档行动力、三档光谱核心、两档竞技场，以及召唤、精灵之花、英雄升级、装备强化和登录。国服“誓约召唤”和国际服“圣约召唤”按同一任务处理，未完成项的顺序可以不同。列表只向下扫描，边读边保存，完整识别到已完成的“每日登录”就结束，不再寻找物理底部或向上重扫。登录下方都是已完成项，无需逐行读取；未读到的已知项目按完成状态补齐，并将完成项奖励合计与当前总活跃核对，防止漏读上方未完成项。每行的标题、进度和活跃奖励都完整时才记录；滚动中被截断的行留待下一屏。没有确认登录边界、活跃不符、数值不可靠或中途跨过服务器刷新时间时，清除旧计划，5分钟后复查。进度绑定服务器和语言，切换设置后不沿用另一服的记录。

未满100活跃时，优先执行已启用且已到期的免费召唤、圣域日常、竞技场和战斗。固定模式按下一个可获得活跃的档位分批，完成一批后回到每日页确认进度。后台托管只有点击结算后，每日任务才统计对应体力消耗；启动托管或后台战斗完成都不能提前计入。已经开始的托管保留预留并等待结算确认，期间每日体力进度未变属于正常情况，不能因此重复启动或追加托管；结算确认后再回查每日页，以实际进度为准。托管期间独立完成的快速战斗已经消耗体力，应单独安排每日回查，包括燃竭模式先托管后快战的流程，不需要等托管结束；没有实际完成快战时，单纯启动托管不触发回查。英雄升级和装备强化暂时只识别，没有自动执行入口。核心奖励只计入实际观察到的收益，不单独安排消耗核心的任务。

执行记录保存次数额度、预留及剩余量，不在战斗中直接累加每日体力进度或活跃。回查读取游戏内实际进度，一次领取当时全部可领奖励；满100并确认领奖后，不再为当日目标安排多余回查。

圣域收菜按本次点击的领取种类判断回查。企鹅、萝卜和照料不会推进精灵之花每日，只有点过花的领取入口才安排回查；不再用“领过任意奖励”代替。领取图标共用模板，根据固定行坐标区分，不需要分别裁剪相同图标，也不会把领取动作直接记成任务完成。

100活跃和奖励领取分别确认，超过100的实际读数也保留。点击宝箱后，需要再次看到稳定的每日页面，确认没有仍可领取的宝箱，才记录领奖完成；点击过、网络提示或读取失败都不代表成功。全部领取后列表消失是正常状态，不再扫描缺项。达到目标后不再为每日额外追加或回查，其他已启用任务继续按同一优先级表和原设置执行。

这版按当前任务配置优先安排，不额外开启任务，也不提前打断未到期的等待。原定次数用完仍不足100时，估算其他已启用、计划在本次刷新前执行的任务，以及同一任务尚未使用的其他额度：预计能补足就等；预计补不足才追加下一个奖励档位所需的次数。追加受实时旗帜、行动力和游戏可用次数限制，不购买资源，不增加生命之叶额度。资源不足时保留进度复查，不能保证任意配置都能自动满活跃。

竞技场挑战次数、快速战斗次数和托管单位分别保存已用及剩余额度，不相互换算。比如竞技场固定10次，可以先做5次回查每日，达到目标后再做余下5次；回查和重启不会重新取得10次。每日优先下，副本可以先完成小批快速战斗；回查后继续剩余快速次数和托管。普通托管最低一单位，每单位按80行动力选择预算，实际活跃仍以回查结果为准。追加托管必须完全由现有行动力覆盖，并强制优先使用行动力；原固定托管仍遵循用户设置，并核对当前行动力和生命之叶库存，资源不足时不让其他任务一直等待。燃竭模式、异界讨伐及不支持的组合保留原流程。

这里是按里程碑分批，并估算其他任务能否补足，没有穷举所有路线的全局最优组合。免费项目、现有额度和实际资源是判断依据；达到100并确认领奖后，继续完成原定余量，不再为每日追加。

额度按服务器和刷新日保存，修改识别语言不会恢复已用额度。消耗前先保存预留，托管启动意图与运行记录关联，只有确认对应结算才解除待确认状态。重复结果不会重复扣账；没有办法确认的中断保留预留并停止继续消耗，不根据每日计数饱和或点击记录推断成功。手动接管的托管不冒充本次已预留批次；跨日的未决记录也不会直接丢弃。
